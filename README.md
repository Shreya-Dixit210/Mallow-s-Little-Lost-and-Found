# Mallow's Little Lost & Found

A whimsical, interactive website for exploring memories, stories, wishes, and little forgotten things.

## Features

- Immersive illustrated backgrounds
- Memory Attic
- Storybook experience
- Wish Maker
- Interactive audio and animations
- Responsive frontend

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- SVG illustrations and image assets

## Run Locally

Open index.html in a browser, or use the Live Server extension in VS Code.

## Project Structure

- assets/ — images and illustrations
- css/ — stylesheets
- js/ — JavaScript modules
- index.html — website entry point
